# Modelo de carrossel – padrão Ótica Beira Rio

- `carrossel2.html`: modelo dos carrosséis (azul royal + amarelo, títulos Anton, pessoa à direita, WhatsApp e logo no rodapé). O conteúdo de cada carrossel fica no objeto `C` no fim do arquivo.
- `carimg/`: fotos de capa geradas no agy (pessoa à direita, fundo de ótica azul desfocado).
- Gerar as imagens: `node shotcar2.js` (precisa do Playwright). Saída em `outcar2/`.
